# Security policy

Please do not disclose suspected vulnerabilities in a public issue or feedback report.

Report them privately through the repository's **Security** tab by opening a private vulnerability
report. Include the affected URL or commit, reproduction steps, impact, and any suggested fix. Do
not include real credentials, personal images, or other sensitive user data.

The maintainer will acknowledge a complete report as soon as practical, investigate it, and
coordinate disclosure after a fix is available. Only the latest deployed version is supported.
