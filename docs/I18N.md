# Internationalization — #42

The first slice supports English and partial Hebrew. Choose Language in the desktop header or More on phones. Browser language is used until a choice is saved. The language change reloads the page; save editor changes first.

## Catalogs

`apps/web/messages/{locale}/{namespace}.json` contains ICU messages. Current namespaces:

| Namespace | Context |
| --- | --- |
| common | Studio navigation, greeting, language selector and gallery accessibility/status labels |
| auth | GitHub feedback login explanation and OAuth error states |
| metadata | Document title and description |

Keep placeholders identical across translations. `imagePosition` uses ICU number formatting; `signedIn` interpolates the account email. Prefer complete phrases over concatenated fragments. Names, emails, URLs and user text should use bidi isolation. Review Hebrew against `docs/brand/VOICE_AND_COPY.md` with a native speaker before marking it complete.

For a new language, add catalogs and its entry/name in `src/i18n/locales.ts`, register catalogs in `src/i18n/request.ts`, and add key-parity tests. This explicit import list is temporary until full extraction introduces namespace discovery and complete catalog validation. Use `useTranslations` in clients, `getTranslations` on servers, and next-intl formatters or Intl with the active locale for new number/date displays. Missing translated entries in these flat namespaces fall back to English.
